Voltage Drop Calculator: Formula, AWG & Percentage Drop

Calculate approximate voltage loss and percentage drop for a copper circuit using load current, system voltage, conductor size and one-way distance.

Voltage drop formula

The simplified resistance model uses Vd = 2 × K × I × D ÷ CM, followed by percentage drop = Vd ÷ V × 100. The factor of two accounts for the outgoing and returning conductor path in this simplified model.

How conductor size affects voltage loss

Larger conductors have more circular-mil area and lower resistance in this model, so increasing conductor size generally reduces voltage drop for the same current and distance.

Know the limits of the estimate

Real circuits can involve conductor temperature, AC reactance, power factor, installation conditions and other effects. For detailed design, use applicable conductor impedance data and project requirements.
