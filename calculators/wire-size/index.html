Wire Size Calculator: AWG, Ampacity & Voltage Drop

Estimate a copper conductor size from load current, voltage, one-way distance and an allowable voltage-drop target. Use the result as a preliminary calculation and verify ampacity and installation requirements separately.

How wire size is estimated

The simplified voltage-drop model uses conductor circular-mil area, current, one-way distance and allowable voltage loss. The calculator then maps the required area to a listed AWG size.

Wire size is not only about current

A final conductor selection can depend on ampacity, insulation temperature rating, terminal ratings, ambient temperature, adjustment factors, installation method and voltage drop.

Verify against the applicable code

This tool is a planning calculator, not a substitute for the adopted electrical code or manufacturer data. Check the actual conductor dimensions, ampacity tables and project requirements before installation.
