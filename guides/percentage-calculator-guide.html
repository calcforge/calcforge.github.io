Percentage Calculator

Learn how to calculate percentages, percentage change, increases, decreases and common percentage relationships.

1. What is a percentage?

A percentage expresses a ratio out of 100. Convert a decimal ratio to a percentage by multiplying by 100.

2. Find a percentage

To find x percent of P, calculate P × x/100. For example, 15% of 200 is 30.

3. Percentage increase

Percentage increase = (new − original) ÷ original × 100 when the new value is higher.

4. Percentage decrease

Percentage decrease = (original − new) ÷ original × 100 when the new value is lower.

5. Percent change versus percentage points

Relative percentage change and percentage-point difference answer different questions, so the base value must be stated clearly.
